# Промпты для изображений витрины проката

Общие ограничения для всех файлов: фотореалистичная коммерческая съёмка, единый жёлто-чёрный инструмент без узнаваемого бренда; без текста, логотипов и водяных знаков; без людей, кроме `hero-builder.webp`; не копировать чужие бренды и конкретные модели. Жёлтый цвет должен быть акцентом самого инструмента, фон — нейтральным почти чёрным.

## hero-drill.webp — 1600×1000

Широкий hero-кадр для сайта проката: массивный жёлто-чёрный профессиональный перфоратор крупным планом справа, ракурс три четверти снизу, корпус и патрон полностью в кадре. Чёрный дымный бетонный фон, жёсткий контровый свет, тонкий жёлтый кант по краям, мягкое овальное отражение под инструментом, глубокие тени. Слева оставить много чистого тёмного пространства под заголовок. На основе референса ref1, но улучшить реализм материалов, масштаб и читаемость силуэта.

## hero-builder.webp — 1600×1000

Широкий hero-кадр: строитель в жёлтой каске и рабочей одежде стоит справа по пояс, держит на плече кейс с инструментом, уверенный спокойный взгляд. Чёрный дымный фон, жёсткий контровый свет, жёлтый кант, фактурная ткань и естественная кожа, слева чистое тёмное пространство под текст. На основе референса ref6, но улучшить естественность позы и студийный свет. Единственный файл в наборе, где разрешён человек.
